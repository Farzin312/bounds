## 1. Token economics (headline)

Generated by `make benchmark` (`python benchmarks/run.py`) against this repo:

```
# Bounds token-economics benchmark

- Repo: bounds (self / dogfood)
- Subsystem profiled: `models` (source: `src/bounds/models.py`)
- Tokenizer: estimate ~1 token / 4 chars (tiktoken not installed)

| Command | Bounds tokens | Source-equivalent tokens | Reduction |
|---------|--------------:|-------------------------:|----------:|
| `bounds describe models` | 399 | 2,872 | 86.1% |
| `bounds list` | 659 | 52,009 | 98.7% |
| `bounds impact models` | 278 | 2,872 | 90.3% |
| **aggregate** | **1,336** | **57,753** | **97.7%** |
```

> The token-economics block above is **regenerated on demand** via `python benchmarks/run.py`; the source-equivalent counts track the current repo, so they shift slightly as the codebase grows (the reduction percentages stay ~stable).

Aggregate reduction: **97.7%** of source-equivalent tokens. To understand the
`models` subsystem's public API an agent reads ~400 tokens of structured JSON
instead of the ~2,900-token source file; to map all 8 subsystems it reads ~660
tokens via `bounds list` instead of ~52,000 tokens of combined source.

## 2. Retrieval scaling observation

`bounds describe models` is ~400 tokens regardless of how large the
implementation behind `models` grows, because the output is bounded by the
declared public API (~O(public API)). Reading source is ~O(files): the
whole-map source alternative is already ~52,000 tokens at 8 subsystems / 18
files and would keep growing. The wider that gap gets, the more both the token
bill and the lost-in-the-middle / context-rot penalty favor targeted retrieval
— minimal context keeps the model's attention sharp on what matters.

## 4. Determinism & correctness

Structural metrics are zero-LLM (tree-sitter + pure Python) and model-independent.

- Drift recall: every export add / remove / rename in tracked source is caught,
  because declared `exposes` is diffed against the tree-sitter parse.
- False positives on reformatting: ~0 — AST-level hashing ignores whitespace and
  comment-only edits.

## 5. Agent task outcomes

Baseline qualitative observations from dogfooding with Claude Code:

- Understanding a subsystem took 1 `bounds describe <name>` call (~400 tokens)
  instead of opening and reading the corresponding source file(s).
- Mapping the architecture took 1 `bounds list` call instead of grepping for
  `class` / `def` / `export` across 18+ files.
- `bounds impact <name>` surfaced the transitive consumer set directly, instead
  of manually tracing imports to estimate a change's blast radius.
